# azahar-to-home

Azahar to Home - Tools to prepare Pokémon saves for transfer to Pokémon Bank through Azahar-compatible save files.

This repository will contain a Windows application (C# .NET WPF) to import PKHeX .bin box exports, validate Pokémon legality for Ultra Sun / Ultra Moon and the Bank transport rules, inject valid Pokémon into Azahar-compatible saves, and create backups and validation reports.

Initial files and project scaffold will be added to a feature branch.
